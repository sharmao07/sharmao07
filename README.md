### 🌟 About Me

I am a software developer focused on building functional, elegant tools across native desktop environments and modern web platforms. My work centers on native macOS development with Swift and SwiftUI, local-first AI experimentation, and open-source tooling designed to make developer workflows smoother.

- 🍎 **Native macOS Engineering:** Building fluid, lightweight desktop software using Swift, SwiftUI, AppKit, and Apple's Vision ML framework.
- 🌐 **Modern Web Development:** Crafting responsive, accessible web interfaces with TypeScript, Next.js, and React.
- 🤖 **Local-First AI & Automation:** Experimenting with local model inference (Ollama), privacy-first memory systems, and Discord bot architectures.
- 🤝 **Open-Source Collaboration:** Passionate about community tools, good-first-issue discoverability, and clean documentation.
- ⚡ **Fun Fact:** Easily distracted by anything even remotely related to cats! 🐾
